# 개인정보처리방침 (LastDone)

**시행일자:** 2026년 5월 11일

LastDone(이하 "앱")은 사용자의 개인정보를 소중히 다룹니다. 본 방침은 앱이 수집·이용하는 정보의 범위와 목적, 제3자 제공 여부, 사용자 권리를 안내합니다.

## 1. 수집하는 정보

앱은 사용자의 개인 식별 정보(이름, 이메일, 전화번호 등)를 별도로 수집하지 않습니다. 사용자가 앱 내에서 등록하는 항목·카테고리·메모·날짜는 사용자의 기기 내부에만 저장되며 외부 서버로 전송되지 않습니다.

광고 표시를 위해 Google AdMob SDK가 다음 정보를 수집할 수 있습니다.

- 광고 ID (Advertising ID)
- 대략적 위치 (IP 기반)
- 기기 정보 (모델, OS 버전 등)

이 정보의 수집·이용·보관은 Google의 정책에 따릅니다.

## 2. 권한 사용

| 권한 | 용도 |
|---|---|
| 알림 (POST_NOTIFICATIONS) | 사용자가 설정한 항목의 알림 표시 |
| 정확한 알람 (SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM) | 정시 알림 발송 |
| 부팅 완료 수신 (RECEIVE_BOOT_COMPLETED) | 기기 재시작 후 예약 알림 복구 |
| 인터넷 / 네트워크 상태 | 광고 표시 |

알림 및 알람 권한과 관련된 모든 처리는 기기 내부에서 실행되며 외부로 데이터가 전송되지 않습니다.

## 3. 제3자 제공

앱은 다음 서비스를 사용합니다.

- **Google AdMob** — 광고 게재. [Google 개인정보처리방침](https://policies.google.com/privacy)
- **Google Play 서비스** — 광고 ID 제공

위 외 제3자에게 사용자 정보를 제공하거나 판매하지 않습니다.

## 4. 데이터 보관 및 삭제

앱이 사용자 기기 내부에 저장하는 데이터(항목, 카테고리, 기록)는 앱을 삭제하면 함께 제거됩니다. 별도 서버에 저장되는 사용자 데이터는 없습니다.

## 5. 어린이 개인정보 보호

앱은 만 14세 미만 사용자를 대상으로 하지 않으며, 의도적으로 해당 연령대의 개인정보를 수집하지 않습니다.

## 6. 광고 개인화 거부

사용자는 Android 시스템 설정에서 광고 개인화를 거부할 수 있습니다.

- 설정 > Google > 광고 > "맞춤설정된 광고 사용 안함"
- 또는 설정 > 개인정보 > 광고 (기기에 따라 메뉴 위치 상이)

본 방침이 변경될 경우 앱 내 안내 또는 본 페이지를 통해 고지합니다.
